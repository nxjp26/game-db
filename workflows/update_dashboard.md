# 워크플로우: 대시보드 업데이트

**목적**: `dashboard_v*.html` 파일의 기업 데이터를 업데이트하고 관계자에게 파일을 재공유한다. 서버·인터넷 연결 불필요 — 단일 자립형 HTML 파일.

---

## 사전 준비

- 업데이트할 기업의 최신 정보 (IR 자료, 결산공고 등)
- 텍스트 편집기 (VS Code 권장)
- 현재 대시보드 파일: `dashboard_v*.html`

---

## STEP 1 — 기존 파일 복사 및 버전 업

1. 현재 파일을 복사해 버전을 올린다.
   - 예: `dashboard_v3.html` → `dashboard_v4.html`
2. 이전 버전은 삭제하지 않고 보존한다.

---

## STEP 2 — 데이터 수정 방법

HTML 파일을 텍스트 편집기로 열고, `const D = [` 로 시작하는 JavaScript 배열을 찾는다.

### 기존 기업 수정

1. 수정할 기업의 오브젝트를 찾는다 (기업명으로 검색)
2. 해당 필드 값을 업데이트한다
3. `src` 필드를 `"upd"`로 변경한다
4. `fix` 필드에 수정 내용을 기재한다:
   ```
   "fix": "2026-04 / mk: 120억엔→145억엔 / 출처: 2025년도 결산단신"
   ```

### 신규 기업 추가

배열 끝에 아래 형식으로 오브젝트를 추가한다:
```json
{
  "n": "会社名",
  "nk": "회사명",
  "ct": "일본",
  "bz": "개발/운영",
  "gn": "서브",
  "ma": "N",
  "mr": "판단 근거 기재",
  "mk": null,
  "rv": null,
  "mg": null,
  "rep": "대표자명",
  "tt": "타이틀1, 타이틀2",
  "ch": "회사 특징 설명",
  "pr": "장점",
  "cn": "리스크",
  "sh": "주주구조",
  "src": "short",
  "emp": null,
  "fix": null
}
```

### 필드 입력 규칙

| 필드 | 규칙 |
|------|------|
| `n` | 일본어 원문 |
| `nk` | 한국어 기업명 (없으면 생략 가능, 일본어 fallback) |
| `ma` | `"O"` / `"T"` / `"X"` / `"N"` 중 택일 |
| `mk` / `rv` | 숫자 (엔 단위). 예: 1억엔 = `1e8`, 100억엔 = `1e10`. 비공개는 `null` |
| `mg` | 소수점 1자리 숫자 (%). 예: `-5.2`. 비공개는 `null` |
| `src` | `"orig"` / `"short"` / `"upd"` |
| `fix` | `src="upd"` 인 경우 필수. 날짜/변경필드/출처 형식 |

---

## STEP 3 — 비밀번호 확인

파일 내 `GATE_PASSWORD` 상수 값을 확인한다.
변경이 필요한 경우:
```javascript
const GATE_PASSWORD = '새비밀번호';
```

---

## STEP 4 — 로컬 검증

1. HTML 파일을 Chrome 또는 Safari로 열기
2. 비밀번호 gate가 정상 표시되는지 확인
3. 비밀번호 입력 후 대시보드가 열리는지 확인
4. 수정된 기업 카드를 찾아 데이터 정확성 확인
5. 검색·필터 동작 확인

---

## STEP 5 — 파일 공유

검증 완료된 HTML 파일을 아래 방법 중 하나로 공유한다:

| 방법 | 절차 |
|------|------|
| **Google Drive** | 기존 파일을 새 버전으로 덮어쓰기 업로드 → 기존 공유 링크 유지 |
| **이메일** | `dashboard_v*.html` 첨부 발송 |
| **사내 파일서버** | 지정된 공유 폴더에 파일 덮어쓰기 |
| **Slack / Teams** | 파일 업로드 → 관계자에게 공유 |

수신자는 파일을 다운로드 후 **Chrome / Edge / Safari** 중 아무 브라우저로 열면 된다.

---

## 오류 대응

| 증상 | 원인 | 해결 방법 |
|------|------|---------|
| 대시보드 빈 화면 | JavaScript 문법 오류 | 브라우저 개발자 도구(F12) → Console 탭에서 오류 확인. 주로 JSON 쉼표 누락 |
| 기업 카드가 안 보임 | 필터 상태 | 필터 초기화 버튼 클릭 또는 페이지 새로고침 |
| 숫자 표시 이상 | mk/rv 단위 오류 | 엔 단위 숫자 확인 (1억 = 100000000 또는 1e8) |
| 비밀번호 gate 안 나옴 | sessionStorage에 저장됨 | 시크릿 모드로 열어 확인 |

## 업데이트 이력 기록

업데이트 완료 후 아래 형식으로 이력을 남긴다:

```
## 2026-04-xx — v4 업데이트
- 수정: ドリコム — mk 117억엔→132억엔 (2025년도 결산단신)
- 수정: gumi — rv 업데이트, src=upd 처리
- 신규: XXX 추가 (src=short)
- 공유: Google Drive 덮어쓰기 / 이메일 발송
```
