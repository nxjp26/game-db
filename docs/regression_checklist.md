## 1. 검색 (Search)
- [ ] 한국어 기업명 검색 → 결과 필터링
- [ ] 일본어 기업명 검색 → 결과 필터링
- [ ] 검색어 지우면 전체 목록 복원
- [ ] 검색 중 탭/필터 전환 후 검색어 유지

## 2. 탭 필터 (Tab)
- [ ] 전체 탭 → 237개 기업 표시
- [ ] MA 탭 → 해당 기업만 표시
- [ ] Accel 탭 → Accel 분류 기업만 표시
- [ ] 탭 전환 시 카운트 올바름

## 3. 상세 필터 (Filter)
- [ ] 국가 필터 (일본 / 한국 / 중국 등)
- [ ] 장르 필터 (서브컬처 / 비서브 등)
- [ ] 업종 필터 (개발/운영 / 판매원 등)
- [ ] 복수 필터 AND 조건으로 동작
- [ ] 필터 초기화 → 전체 복원

## 4. 정렬 (Sort)
- [ ] 시총 정렬 (높은순/낮은순)
- [ ] 매출 정렬
- [ ] 이익률 정렬
- [ ] 기본값(순서순) 복원

## 5. 카드 클릭 → 상세 모달
- [ ] 기업명(한국/일본) 표시
- [ ] 시총·매출·이익률 수치 표시
- [ ] 기업특징·장점·단점 텍스트 표시
- [ ] 주주구조·대표이사 표시
- [ ] 수정메모(있는 경우) 표시
- [ ] 모달 닫기 (X 버튼 / 배경 클릭 / ESC)

## 6. 통계 요약 (상단 수치)
- [ ] 총 기업 수 237개
- [ ] MA 검토 기업 수
- [ ] 평균 시총·매출 수치
